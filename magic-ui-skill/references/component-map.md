# Component selection map

Choose by product purpose first, then by visual effect.

| Product need | First choice | Use it for | Avoid when |
| --- | --- | --- | --- |
| Focused, important content | Magic Card | One quote, memory, or primary action | Every card in a grid |
| Selected or syncing state | Border Beam / Shine Border | A live connection, saved state, or active capsule | Permanent decoration |
| Live stream | Animated List | Messages, events, jobs, or memory candidates | Static editorial content |
| Compact navigation | Dock | A small set of spatially related destinations | Primary mobile navigation with long labels |
| Ambient background | Dot Pattern / Noise Texture / Particles | Quiet depth behind a page | Behind dense text or forms |
| Reveal of meaningful copy | Blur Fade / Text Reveal | A message that arrives or is being remembered | Every heading on first load |
| Continuous content | Marquee | A genuinely ongoing ticker or archive | Filling empty space |
| Product showcase | Bento Grid | Three or more capabilities with different weights | A private tool where content should feel intimate |
| Logs or technical state | Terminal / Code Comparison | Diagnostics, prompts, or system traces | The user's personal or reflective surface |

## Amid first-pass recommendation

For the first redesign, choose one of these coherent combinations rather than mixing everything:

### Quiet room

`Magic Card` for Claude's kept note + `Blur Fade` for the daily question + a very low-contrast `Noise Texture` behind the page.

### Living archive

`Animated List` for memory candidates + `Border Beam` only on the currently selected memory + static editorial typography.

### Soft instrument

`Dock` for the four rooms + one slow ambient `Particles` layer + `Shine Border` for the active room.

The first option is the safest for Amid's private, reflective tone. Do not combine all three in the same screen.
